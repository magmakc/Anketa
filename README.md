# Обработчик анкет

Программа читает файл с анкетами, проверяет поля и формирует два файла:
список принятых анкет и список брака с причинами отказа.

## Требования

- Python 3.10 или новее

## Запуск

    python main.py

## Входной файл

`anketa.txt` в папке с программой. По одной анкете в строке, поля через `;`:

    ФИО;почта;телефон;группа

Пример лежит в файле `anketa.txt`.

## Результат

- `ok.txt` — принятые анкеты;
- `errors.txt` — отклонённые строки с причиной отказа.

## Структура

- `main.py` — точка входа;
- `validators.py` — проверки полей;
- `report.py` — таблица, список брака, статистика;
- `storage.py` — чтение входного файла и запись результатов.
